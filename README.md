### 🎮 게임 내용
플레이어는 광산 마을의 광부로 죽을뻔한 위기에서 전설의 광부 스티브의 안배로 살아남았습니다. 이제는 다시 광산으로 들어가 광산 속 몬스터를 물리치고 스티브의 뒤를 잇는 광부가 될 시간입니다.  
- **던전 시스템**
    - 플레이어는 광산 깊은 곳으로 계속 내려갑니다. 더 깊이 내려갈 수록 위험한 몬스터를 만날 수 있지만, 그만큼 더 좋은 보상을 얻을 수 있습니다.
    - 탐험을 계속 할지는 당신의 선택입니다.
